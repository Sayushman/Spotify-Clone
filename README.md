Spotify Clone 

A simple and responsive Spotify-like music player built using HTML, CSS, and JavaScript. This project mimics the basic functionality of Spotify — allowing users to play/pause songs, 
see the progress bar, and enjoy a beautiful interface.

---

 Features

 Play & Pause functionality  
 Custom music library (stored locally)  
 Display of current song title and cover  
 Progress bar that updates with the song  
 Click to seek feature  
 Modern UI inspired by Spotify

---

 Tech Stack

HTML5 – Structure  
CSS3 – Styling and layout  
JavaScript  – Core functionality
